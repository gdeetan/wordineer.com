    How to Use the Filters

    Three filters control what you get: Genre, Gender, and Style. You can use any combination — or leave all three on "Any" for a random mix across everything.

    Genre sets the world the character lives in. Fantasy pulls from archaic, mythic-sounding name pools. Sci-Fi uses sharp, abbreviated phonetics that feel technological. Realistic gives you contemporary names you'd find on a college campus. Historical draws from real medieval and ancient European name traditions. Horror reaches for the gothic and unsettling — names that carry a certain weight.

    Gender filters between male, female, and neutral name pools. Set it to "Any" and the generator mixes all three in a single batch, which is useful when you're building a cast of characters and want variety without switching filters repeatedly.

    Style determines the vibe tag each name gets paired with. Heroic gives you tags like "war-hardened soldier" and "chosen champion." Mysterious pairs names with "shadow walker" and "keeper of secrets." Common goes for "town guard" and "traveling merchant" — useful for supporting characters. Dark reaches for "cursed wanderer" and "death's herald." Whimsical lands on "mischievous trickster" and "luck-touched fool." Set Style to "Any" and each name gets a randomly assigned vibe.

    Each batch produces 10 results. Click "Generate Names" or press Enter for a fresh set. The "Regenerate" button does the same thing with one fewer click.

    What Makes a Great Character Name

    A character name has to do several things at once. It needs to fit the world, feel distinct from other characters in the same story, be easy enough to read without breaking immersion, and ideally carry some hint of personality. That's a lot to ask of a word.

    Memorability

    Short names with strong consonants tend to stick. Readers process "Kael" faster than "Kaelindrothar" — and they'll remember it more accurately after 300 pages. If you use a long name, make sure there's a natural short form characters can use in dialogue. "Thaddeus" works if people call him "Thad." If the full name appears every time, readers start skipping over it.

    Setting fit

    A name that clashes with the setting pulls readers out. "Kevin" in a high fantasy epic is distracting. "Aelindra" in a gritty contemporary thriller is equally off. The genre filter here handles the heavy lifting — names in each pool were chosen to feel right in their setting. That said, deliberate genre-clashing can be a useful device: an ordinary name in a fantasy setting can signal that the character doesn't belong, which might be exactly what you want.

    Distinctiveness

    Every main character needs a name that's clearly theirs. In an ensemble cast, avoid starting multiple names with the same letter — readers will confuse them. Watch for names that look similar when skimmed at reading speed: Kael and Kale, Mira and Myra. If you're writing a long work, keep a running list and check for collisions as you add characters.

    Tips by Genre

    Fantasy

    Fantasy names work best when they feel like they could belong to a language — even a made-up one. The best approach is to pick a phonetic style and stick to it across your world. If your culture uses a lot of hard consonants (Dravon, Gareth, Valdris), a name like "Lyra" will feel like it's from a different book. For more genre-specific options, the Fantasy Name Generator focuses entirely on this space with dedicated pools for different fantasy cultures.

    Sci-Fi

    Sci-fi names often signal a future that's evolved from current naming traditions — abbreviated, combined, or slightly altered. Short names with unusual letter combinations (Jax, Nyx, Vex) work well for protagonists. For supporting characters in a crew or ensemble, mixing very short names helps readers keep track. Avoid names so unusual that readers can't form a mental sound for them.

    Realistic

    For contemporary fiction, realistic names carry cultural and class signals that genre names don't. "Aaron" and "Marcus" land differently. Think about the character's background, decade of birth, and region before picking — or let the vibe tag guide you. A "town guard" named "Quinn" reads differently than a "fallen noble" with the same name.

    Historical

    Historical names do research work for you: they ground the reader in the period immediately. The name pools here draw from real medieval European traditions — Scandinavian, Anglo-Saxon, Germanic. For a narrative set in a specific time and place, doing additional research into period-appropriate names is worth it. But for games, fiction, and worldbuilding where historical accuracy is approximate, these pools work well.

    Horror

    Horror names are gothic by nature — Alistair, Corvus, Desdemona, Silas. They carry a sense of age and formality that feels slightly out of place in modern settings, which is exactly right. The unease often comes from the mismatch between the name's dignity and what the character does. For horror settings with more contemporary characters, mixing horror names with realistic ones creates an interesting contrast.

    How to Use the Vibe Tag

    The vibe tag — "brooding scholar," "reluctant hero," "fallen noble" — isn't a character sheet. It's a starting point. Its job is to give you a mental image fast enough to feel whether the name fits the role you have in mind.

    If the name and vibe tag click together immediately, that's useful signal. If they feel wrong for each other, that's also useful — it means the name might belong to a different kind of character. A name paired with "war-hardened soldier" might actually be perfect for your village elder, and the friction tells you something about the character's hidden past.

    Writers use vibe tags differently than game designers. A novelist might use the tag as the seed of a backstory — "cursed wanderer" becomes a whole arc. A tabletop GM might use the tag to run the character in the first session while the full concept develops. Either way, the tag is a tool to avoid the blank-page feeling when you're naming character #12 in a cast.

    Frequently asked questions

    Can I use these names in my published work?
    Yes. Names aren't copyrightable, so you're free to use any generated name in fiction, games, scripts, or published work. If a name closely resembles a famous existing character, do a quick search — but for most names there's no legal concern.
    How does the vibe tag help?
    The vibe tag — like "brooding scholar" or "war-hardened soldier" — gives the character a starting personality at a glance. It's a springboard: use it to quickly feel whether a name fits the role you have in mind, without committing to a full backstory first.
    What's the difference between genre filters?
    Each genre draws from a dedicated name pool: Fantasy names have archaic, mythic sounds. Sci-Fi uses sharp, abbreviated phonetics. Historical draws from real medieval European traditions. Realistic names are contemporary. Horror names are gothic and formal. Select "Any" to mix across all genres in one batch.
    Can I get male and female names in the same batch?
    Yes — set the Gender filter to "Any" and each batch will randomly mix male, female, and neutral names. Useful when you're building a cast and want variety without switching filters between clicks.
    Does the generator use AI?
    No. The generator uses handpicked name pools filtered by genre and gender. No language model is involved, which means results are consistently pronounceable and genre-appropriate — not random syllable strings.
    How many names can I generate?
    As many as you want. Each click produces a fresh batch of 10. No limit, no paywall — generate until something clicks.
