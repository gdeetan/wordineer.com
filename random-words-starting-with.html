    If you already know the length

    Don't start here. Use a 5-letter generator (or 3, 4, 6) and filter from there. This page is only for when the first letter is the one thing you know. For any word at all, use the homepage generator.

    Questions

    Is this every English word that starts with that letter?

    No. Each page is a defined list with definitions, not a dump of the dictionary. X has 30 words. I has 891 because that list picked up a lot of in- words. S is still the letter that usually wins in a real dictionary.

    Why are Q, X, and Z so short?

    English. Q almost always needs a U. Almost nothing native starts with X. Z is rare. There isn't a longer list hiding behind those pages.
