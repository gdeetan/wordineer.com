      About Wordineer

      Wordineer (wordineer.com) is a free, ad-supported collection of online word and language tools built by Garrick Dee. Originally created as a vocabulary resource for his homeschooled son, Wordineer has grown into a suite of generators, word lists, and text utilities used by writers, students, educators, and developers. All core tools are free with no account required. Word data is produced through a Python pipeline drawing on NLTK and WordNet, then curated by hand for accuracy and usability.

      Datasets

      All datasets are served directly from wordineer.com/data/ and are free to download, build upon, or republish under CC BY 4.0 with attribution.

      Core Word List

      ~8,000 curated English words, each with part of speech, difficulty level (easy / medium / hard), and a concise definition. The backbone of Wordineer's random word generator.

      Format: JSON Size: ~809 KB Methodology: Python + NLTK / WordNet, hand-curated Updated: May 2025 Licence: CC BY 4.0

      English Dictionary

      Definitions lookup table for tens of thousands of English words. Used to power in-tool definitions across the site. Extracted from WordNet via a Python pipeline.

      Format: JSON Size: ~2.4 MB Methodology: WordNet extraction via Python Updated: May 2025 Licence: CC BY 4.0

      Age-appropriate spelling bee word lists for kindergarten through 7th grade, each entry with a definition and difficulty tag. Built for educators running classroom spelling bees.
