What is a random number between 1 and 30?

Thirty is a very common class size and event size. Each of the thirty integers represents a 3.3% chance of being selected with this tool. This function can generate numbers in the range of 1-30, i.e. class lists, a monthly calendar, group sizes of thirty, and a raffle with thirty tickets. This tool uses the unseeded, seeded and hardware entropy seeded versions of JavaScript's Math.random function.

Pool mode: the classroom tool

For teachers with big classes (30+ students), the Pool mode is the most important feature. In this mode, the generator first shuffles the numbers of all students in the class. Then, for each generated number, the tool picks the next number from the (shrinking) pool of remaining student numbers, without replacement. The progress bar shows how many students are left in the pool. This avoids the worst problem for teachers with large classes: keeping calling the same students.

Distribution: buckets of three

The distribution chart groups the results from each generated number into 10 groups of 3 numbers each (e.g., 1 to 3, 4 to 6, 7 to 9, 10 to 12, all the way to 28 to 30). Each bucket should fill roughly equally often after several number generations to confirm that the distribution is uniform and not biased to any part of the 1–30 range.

Frequently asked questions

Is this truly random?

Yes. Math.random() is seeded from hardware entropy. Each of the 30 numbers has a 3.3% chance (or a 1 in 30 change) of being selected, so it is statistically uniform and unbiased.

What is pool mode for 1–30?

This mode generates a pool of all 30 numbers in random order. Each number is called once before any number is called again. This mode is ideal for random selection from a class of 30 students where every student is called once before any student is called again.

Can I exclude specific numbers?

You can also specify numbers to be excluded from drawing using a comma-delimited list in the “Exclude numbers” field. This can be particularly useful for classes with less than 30 students (i.e. with unused numbers in the roster).

What does the distribution chart show?

After 10 numbers are generated, the chart is grouped into 10 buckets of 3 numbers each (1–3, 4–6, 7–9, 10–12, 13–15, 16–18, 19–21, 22–24, 25–27, 28–30). As you use the generator, each bucket should ideally be filled equally, so there is no bias to any portion of the range.
